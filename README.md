# 📜 عيون المخطوطات العرفانية
> **أرشيف رقمي مخصص لحفظ ونشر تراث السالكين المخطوط.**

---

## 🖋️ عن المشروع
هذا المستودع هو مبادرة لجمع ورقمنة المخطوطات التي تُعنى بـ **العلوم العرفانية** و**التصوف الإسلامي**. نهدف من خلاله إلى تسهيل وصول الباحثين والسالكين إلى كنوز التراث التي توضح معالم الطريق والسلوك.

## 📂 محتويات الأرشيف
يضم هذا المشروع مخطوطات تتناول المواضيع التالية:
* **علوم العرفان:** نظريات السلوك والشهود.
* **التصوف:** رسائل كبار المشايخ والعارفين.
* **التراث الروحي:** أدعية، أوراد، وشروح حكم قديمة.

## 🌐 رابط المعرض الرقمي
يمكنكم تصفح المخطوطات بشكل بصري عبر الرابط التالي:
👉 **[رابط موقعك على Netlify أو GitHub Pages]**

## 🛠️ المساهمة
نرحب بمساهمة الباحثين والمحققين:
1. إذا كنت تملك مخطوطة نادرة وتريد رقمنتها.

3. يرجى فتح **Issue** أو إرسال **Pull Request**.
